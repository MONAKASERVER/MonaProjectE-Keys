# MonaProjectE Keys

Minecraft 26.1.2 / Fabric用のクライアント補助Modです。MONAKA SERVERのMonaProjectEへ、本家ProjectEと同じキー操作だけを送信します。

- `V`: チャージ変更
- `C`: 追加機能
- `R`: 投射能力
- `G`: モード変更
- `X`: ブーツ能力切替
- `Shift+X`: 兜能力切替

すべてのキーはMinecraftの「設定 → 操作設定 → キー割り当て → MonaProjectE」から変更できます。
兜だけを独立したキーで操作したい場合は、初期状態で未割り当ての「兜能力切替（直接キー）」へ好きなキーを設定してください。

送信できる値は上記6種類だけです。サーバー側で所持品、署名、権限、クールダウンを再検証します。ModなしのJava版および統合版は `/pe abilities` を使用できます。
